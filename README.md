# Personal Portfolio Website

A modern personal portfolio website developed using Streamlit with custom HTML and CSS components to create a visually appealing and interactive user interface.

## Live Demo

🌐 https://geethika-portfolio.streamlit.app/

## Features

* Responsive and clean user interface
* Custom HTML and CSS styling
* Smooth animations and hover effects
* Glassmorphism design elements
* Interactive project and skill cards
* Well-organized sections for projects, skills, certifications, and achievements
* User-friendly navigation and layout

## Tech Stack

* Python
* Streamlit
* HTML5
* CSS3

## Installation & Setup

### Clone the repository

```bash
git clone https://github.com/geethika477/Portfolio.git
```

### Navigate to the project directory

```bash
cd Portfolio
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run portfolio.py
```
